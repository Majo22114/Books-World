# Books-World
## Este proyecto es una forma de dar a conocer a las personas distintas obras, a través de distintas categorías para que elijan la que más les gusta para poder desarrollar un gusto por la lectura.
## María José
Esta elaborado y diseñado para ser compensible para cualquier porsona que visite el sitio.
## Funciones:
### Usuarios
- Los usuarios que visiten la pagina podran ver las obras de distintos autores y de distintos géneros.
- Esta diseñado para ser utilizado por personas adultas y adolecentes para motivar su habito lector.
### Interfaz
- Tiene un diseño sencillo y moderno para que sea facil de comprender y atractivo para las personas.
- Cuenta con un menú de navegación para facilitar la visita a la pagina.
## Conclusión
Este proyecto permitió desarrollar una posible solución para poder fomentar la lectura en adolecentes y adultos. En el futuro, el proyecto podría ampliarse incorporando nuevas funcionalidades y mejoras.
